## 車泊供電四大核心環節

「只買電池，其他隨便接」是車泊火燒車的主因。一套安全的供電系統由四個模組組成，最弱的一環決定安全極限。

**🔋 1. 儲能核心（鋰鐵電池 + BMS）**
- 系統的心臟
- BMS 決定放電電流的天花板
- 若要吹冷氣，BMS 必須具備 **200A 以上**的持續輸出能力

**🔌 2. 輸出核心（純正弦波逆變器）**
- 嚴禁使用便宜的「模擬波/修正波」逆變器，會直接燒毀冷氣壓縮機、冰箱與微波爐
- 必須使用「純正弦波」，且瓦數必須大於設備的啟動峰值

**⚡ 3. 補電核心（充電與升壓系統）**
- 若要邊開車邊充，絕對不能接點煙器（會融毀）
- 必須從主電瓶拉線，並強制加裝「DC-DC 車充升壓器」以控制電流與穩壓

**🛡️ 4. 物理防線（保險絲與 AWG 矽膠線）**
- 距離電池正極 **15 公分內**必須安裝大電流熔斷絲（ANL）
- 100A 以上的電流，線材截面積未達標，就是一條發熱的電阻絲

## 逆變器要選幾瓦？純正弦波和修正波有什麼差別？

> 先說最重要的一件事：**無論瓦數選多大，都必須選擇純正弦波（Pure Sine Wave）逆變器。**

**純正弦波 vs 修正波比較：**

| | 純正弦波 | 修正波／模擬波 |
|--|---------|--------------|
| 輸出波形 | 與市電完全相同 | 波形失真 |
| 適用設備 | 所有電器均可安全使用 | 馬達類設備長期使用會過熱損壞 |
| 壓縮機、馬達 | 不會異常發熱 | 可能燒毀冷氣、冰箱、抽水機 |
| 敏感電子 | 筆電、醫療器材安全無虞 | 咖啡機、微波爐可能運作異常 |
| 價格 | 較高 | 便宜，但隱性損失極高 |

**逆變器瓦數選擇原則：** 額定功率必須大於所有可能同時使用的交流設備功率加總。

**常見設備功率參考：**
- 微波爐：約 1000~1200W
- 吹風機：約 800~1200W
- IH 爐：約 1200~1400W
- 咖啡機：約 800~1500W
- 筆電 + 照明 + 手機充電：約 100~300W
- 駐車冷氣（110V 款）：約 600~1200W

**常見情境建議瓦數：**
| 使用情境 | 建議瓦數 |
|----------|----------|
| 輕度車泊（筆電 + 照明 + 手機） | 1000W 以上 |
| 一般車泊（加吹風機或小電鍋） | 1500W~2000W |
| 重度車泊（微波爐 + 吹風機 + 其他） | 2500W 以上 |
| 餐車（同時多台設備） | 3000W 以上，依清單實際計算 |

> ⚠️ 馬達類設備（冷氣、冰箱、抽水機）啟動瞬間電流可達穩態的 3~6 倍。例如 600W 冷氣啟動瞬間可能需要 1800W 以上。

## 2500W 逆變器的正確使用方式

逆變器跳機的真正原因：同時用電超過上限。

**常見錯誤情境：**
- 微波爐（1200W）+ 吹風機（1000W）= 2200W → 接近上限，再加任何設備即會跳機

**正確使用原則：**
1. **高功率設備錯開使用：** 微波爐加熱完畢後，再開吹風機，不要同時運行兩台大功率設備
2. **隨時心算當前總瓦數：** 所有開啟設備的功率加總維持在 2500W 以內
3. **直流設備優先選用：** 12V/24V 的車用冰箱、冷氣直接走電池，不佔逆變器容量

## 逆變器要裝在哪裡？離電池多遠？線要多粗？

**原則：越靠近電池越好。**

- 逆變器是整個系統電流最大的負載，線材越長電阻越大，電壓降越嚴重
- 電壓降過大導致逆變器頻繁低壓報警跳機
- 建議逆變器與電池的連接線長度控制在 **1 公尺以內**，最長不超過 1.5 公尺

**12V 系統逆變器線材建議規格：**

| 逆變器功率 | 最小線徑 |
|------------|---------|
| 1000W 以下 | 至少 4 AWG（約 21mm²） |
| 1500W~2000W | 至少 2 AWG（約 33mm²） |
| 2500W 以上 | 至少 1/0 AWG（約 50mm²），或雙線並聯 |

**安裝要點總整理：**
- 📍 **位置：** 緊鄰電池安裝，連接線越短越好
- 📏 **線材：** 依逆變器功率選對應 AWG，使用高純度銅線
- 🔒 **保險絲：** 逆變器正極線靠近電池端，必須加裝 ANL 大電流保險絲
- 🔧 **端子壓接：** 線材兩端端子必須確實壓緊，接觸不良是發熱的最大元兇
- 🌬️ **通風：** 逆變器工作時會發熱，安裝位置需保持通風，勿緊貼木板或隔熱材

## 電池可以同時接多個設備嗎？需要加裝匯流排嗎？

可以！小型露營車、餐車、改裝車廂**不需要額外加裝匯流排**（Bus Bar）。

**為什麼不需要匯流排：**
- 電池輸出端子直接配置分支線路即可，架構簡單清楚
- BMS 已內建完整的過電流與短路保護
- 加裝匯流排反而增加接點數量，多一個接點就多一個潛在的接觸不良風險

**真正重要的是：每條支路都要裝保險絲**

**保險絲配置原則：**
- 📍 **位置：** 每條支路的保險絲必須裝在靠近電池正極端，距離電池 **15 公分以內**最佳
- ⚡ **規格：** 保險絲額定電流應略高於該支路的正常工作電流，但不能超過線材的安全載流量
- 🔌 **主幹保險絲：** 電池正極出線處建議加裝一顆大電流主保險絲（ANL 型）

**常見多設備配置範例：**
| 支路 | 建議保險絲 |
|------|------------|
| 逆變器 | 大電流，建議獨立拉粗線，搭配 ANL 保險絲 |
| 車用冰箱 | 中電流，獨立一條線，搭配 30A 保險絲 |
| 照明 / USB 充電 | 小電流，可共用一條線，搭配 10~15A 保險絲 |
| 太陽能控制器 / 車充 | 充電迴路，依升壓器規格配對應保險絲 |

## 24V 轉 12V 需要什麼配件？

需要 **DC-DC 降壓轉換器（24V to 12V Converter）**。

**功能：** 將 24V 穩定轉為 12V，適合接所有 12V 設備（車燈、音響、USB 充電器、車載冰箱等）。

**選購建議：**
| 項目 | 規格 |
|------|------|
| 輸入電壓範圍 | 至少支援 20V~30V（適應電池波動） |
| 輸出電壓 | 固定輸出 12V 最佳，避免可變壓版本 |
| 輸出電流 | 根據設備需求：如冰箱需 8A，則選 ≥10A（120W） |
| 保護功能 | 過載、短路、過熱、反接保護 |
| 外殼材質 | 鋁合金散熱片佳，耐用、耐熱性高 |

**常見使用情境：**
- 小功率設備（USB、LED 燈）：用 10A/15A 降壓器（120W~180W）
- 中高功率設備（電磁閥、抽水馬達等）：用 20A~40A 降壓器（240W~480W）

> ❌ 不能直接串電阻或穩壓 IC，功率太大會燒掉。一台降壓器可供多個 12V 設備，但要確保總功率不超過其上限。

## 端子接線有正反面或鎖固磅數的要求嗎？

**正負極（正反面）：** 接線時務必正接正、負接負，不可接反。接反會造成短路、BMS 保護或電池與設備損壞，甚至有起火風險。

**鎖固力道：** 我們的電池正負極端子，建議最大 **5 N⋅m（牛米）**。請用扭力扳手依此規範鎖緊，避免使用氣動工具造成端子因扭力過大而受損滑牙。

**一般端子：** 一定要壓緊，確保線與端子接觸牢固。壓接不實會導致接觸電阻大、發熱、打火，長期可能熔線或引發危險。

**沒鎖緊／沒壓緊會怎樣：**
- 接觸不良：電阻變大、電壓降大，設備無力或斷電
- 發熱：接點處持續發熱，可能熔毀絕緣、端子變形
- 打火、燒熔：大電流時易產生火花，接頭燒黑、熔線，有短路與起火風險
- 間歇斷電：行駛或震動時接觸時好時壞，設備不穩、BMS 誤判

## 多組電池可以並聯使用嗎？

可以！讓你在不更換硬體的情況下直接擴充電池容量。

**並聯運作方式：**
- 每組電池各自搭配一片 BMS，各自獨立保護自己的電芯
- 充放電電流由各組 BMS 自動分配，避免某組承受過大電流
- 任何一組觸發保護時，不影響其他組繼續供電

**並聯注意事項：**
- 建議最多 **4 組**同規格、同容量的電池進行並聯
- BMS 型號需相同或相容
- 並聯前各組電池電壓差需在 **0.1V 以內**
- 線材截面積要足夠承受合計電流

> 並聯系統的接線和設定比單組更複雜，建議由有經驗的改裝廠進行規劃和安裝。

## 把電池安裝在密閉的木作櫃或車廂內，需要預留散熱空間嗎？

**🔋 單純電池（無內建逆變器）：** 鋰鐵電池本身發熱量低，不需要額外散熱。只要依說明書固定、避免日曬與高溫環境即可，無須特別預留散熱孔或風扇。

**⚡ 內建逆變器的電池款式：** 逆變器工作時會發熱，需要散熱。
- 請在櫃體或車廂內預留至少 **5~10 公分**的通風散熱空間
- 避免將逆變器出風口或散熱面緊貼牆板、雜物
- 若空間真的很密閉，可考慮加裝小風扇或開孔對流

---

## 如果是營業餐車使用，電池需要距離熱源多遠？

建議將電池安裝於距離熱源 **50 公分以上**的通風處，若空間允許，**1 公尺以上**更理想。

**原因：**
- 外在熱源會疊加電池本身充放電產熱，容易觸發 BMS 過溫保護，造成斷電或無法充電
- 長期處於高溫環境也會加速電池老化、縮短壽命

**餐車衛生與防蟲：**
- 接線孔、散熱孔或櫃體縫隙可能成為蟲類通道，建議使用防蟲網、密封膠或線孔塞封好孔隙
- 電池與線路周邊保持乾燥、清潔，勿堆積雜物或食物殘渣
- 若電池裝在櫃內，櫃門閉合應密合，避免蟲類鑽入後接觸端子或線路

## 我完全沒有水電背景，可以自己安裝嗎？

可以，但建議善用以下安全支援：

1. **通電前免費圖紙審核：** 選擇 DIY 安裝的客戶，在正式通電前，可將配線照片傳給工程師確認接線方向、線徑規格與保險絲位置

2. **專業改裝廠引薦：** 涉及 DC-DC 車充跨車廂拉線、大電流逆變器整合等較複雜工程，可引薦合作的專業汽車電機行代為施工

3. **BMS 內建多重保護：** 即使操作過程中出現失誤，BMS 會在第一時間介入保護，將風險降到最低

> 沒有任何問題是奇怪的問題，不確定就問，這是最聰明的做法。
